## Notes

- GUI app — it runs indefinitely; close the window to exit. Run in the
  background when launching from an agent session.
- On startup it: shows a splash, opens the Document Pipeline window, runs a
  one-shot discovery scan (~752 files observed on this machine), shows a toast,
  and ~10s later checks GitHub Releases for updates (the running dev build
  reported "Update available: v0.1.1").
- App version at cache generation: `0.1.2-dev`.
- Startup runs a non-blocking LLM-readiness preflight (PR #61). A missing model
  warns and continues — the GUI still launches. If it warns about the legacy
  `qwen2.5-vl` (hyphenated, invalid) model, that config value is auto-migrated to
  `qwen2.5vl:latest` on the next `ConfigManager` load (`_migrate_legacy_config`),
  after which the preflight goes green (verified live: `check_readiness().ok ==
  True`, "Model 'qwen2.5vl:latest' is ready on ollama"). Requires Ollama serving
  and the `qwen2.5vl` model pulled.
- GUI lifetime: the launcher runs `src/main.py` in the foreground and blocks
  until the window is closed, so exit code 0 = the user closed the window (a
  normal, clean shutdown), not a crash. No "persistence quirk" — the app stays
  resident as long as the window is open.
