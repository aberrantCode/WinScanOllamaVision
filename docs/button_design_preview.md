# Main Window Button Design - Enhanced Styling

## Design Overview

The main window buttons have been redesigned with modern gradients, enhanced visual hierarchy, and improved interactivity.

## Button Categories & Colors

### 🔵 Discovery/Analysis Buttons (Blue Gradient)
- **📁 Discover Images** - Primary action for file discovery
- **🔍 Analysis** - Document analysis action
- Gradient: Light Blue (#3B82F6) → Dark Blue (#2563EB)
- Hover: Brighter Blue (#60A5FA → #3B82F6)

### 🟢 Conversion Buttons (Emerald Gradient)
- **📄 Convert Scans** - Convert analyzed scans
- **📑 Convert PDFs** - PDF conversion action
- Gradient: Light Emerald (#10B981) → Dark Emerald (#059669)
- Hover: Brighter Emerald (#34D399 → #10B981)

### 🟣 Settings Button (Purple Gradient)
- **⚙️ Change Settings** - Application configuration
- Gradient: Light Purple (#8B5CF6) → Dark Purple (#7C3AED)
- Hover: Brighter Purple (#A78BFA → #8B5CF6)

### 🔴 Danger Button (Red Gradient)
- **❌ Quit** - Application exit
- Gradient: Light Red (#EF4444) → Dark Red (#DC2626)
- Hover: Brighter Red (#F87171 → #EF4444)

## Design Features

### Visual Enhancements
- ✨ **Smooth gradients** - Left-to-right color transitions for depth
- 🎨 **Color-coded categories** - Visual grouping by function
- 📐 **Rounded corners** (12px radius) - Modern, friendly appearance
- 🔤 **Large, bold text** (16pt) - Excellent readability
- 📏 **Increased height** (70px) - Better touch targets and prominence
- 👆 **Pointer cursor** - Clear interactive affordance

### Interactive States
- **Default** - Gradient from light to dark
- **Hover** - Brighter gradient (visual feedback)
- **Pressed** - Darker gradient (tactile feedback)
- **Smooth transitions** - All state changes animated

### Typography
- Font size: 16pt (large and readable)
- Font weight: Bold
- Text alignment: Left-aligned with icon
- Icon spacing: Double space after emoji for breathing room

## Color Psychology

| Color | Purpose | Emotion |
|-------|---------|---------|
| 🔵 Blue | Discovery/Analysis | Trust, professionalism, focus |
| 🟢 Green | Conversion/Action | Success, progress, go ahead |
| 🟣 Purple | Settings/Config | Creativity, customization |
| 🔴 Red | Danger/Exit | Caution, finality, stop |

## Accessibility
- High contrast text (white on colored backgrounds)
- Large touch targets (70px height)
- Clear visual hierarchy through color coding
- Pointer cursor for interactive elements
